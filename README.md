# webg850

本環境は、Firefox ブラウザで SHARP PC-G850 の動作確認、解析等ができるようにしたものです。

オリジナルの g800.js は SHARP PC-G800 系列全般をサポートしていますが、
本環境は SHARP PC-G850 モードでの動作を想定しています。

## ROMの準備

動作には、PC-G850 系のポケコンから取り出した ROM が必要です。

ROM は実機から取り出した内容 (intel hex ファイル) を

rom00.ihx ... rom0f.ihx .. rom15.ihx

の名前で rom.zip の名前で固めたものを webg850v.htm と同じフォルダから読むようにできていますが、
起動時に ROM をロードするコードは g800main.js の init() にあるので、
取り出したファイル名、拡張子等に合わせて修正してください。

## Firefox の準備

ローカルファイルからの起動ができるように、Firefox の設定が必要です。
firefox_localfile.txt を参照して設定してください。

設定が完了したら webg850v.htm を Firefox で開くと起動します。

## 操作
| ボタン/チェックボックス | 機能 |
|:----------------------|:----|
| ENB ボタン| デバッグ出力窓を有効にします|
| CLR ボタン| デバッグ出力窓をクリアします|
| DISASM ボタン| そばの入力窓のアドレスから、COUNT 長ディスアセンブルしてデバッグ出力窓に表示します。|
| DUMP ボタン| そばの入力窓のアドレスから、COUNT 長ダンプリストをデバッグ出力窓に表示します。|
| REGS ボタン| レジスタダンプをデバッグ出力窓に表示します。|
| STEP ボタン| [BKPT] にチェックが入っていてブレーク状態のとき、ステップ実行します。|
| RUN ボタン| [BKPT] にチェックが入っていてブレーク状態のとき、再びブレーク条件が成立するまで実行します。|
| BKPT チェックボックス| ブレーク機能の有効・無効を切り替えます。Z80 の PC が横の入力窓のアドレスに一致するとブレークします。|
| FETCH チェックボックス| ここにチェックがあるとき、入力窓のアドレスのメモリ READ でもブレークします。|
| RAMSAVE ボタン| 0x0040-0x7FFF までの内容を ram.txt というファイルに intex hex 形式で読み出します。このファイルは同梱の起動用 RAM ファイル(ram.txt)を差し替えて利用することで、保存時の環境を起動時にロードできますが、起動用として利用する場合には電源 OFF を押してから、このボタンを押して RAM の内容を保存してください。|
| LOAD IHX ボタン| intel hex 形式のプログラムをロードできます。|
| BSAVE/BLOAD 自動 チェックボックス| ここにチェックがあるとき、BASIC の BSAVE で 11pin インターフェースへ出力される内容を復号し、ファイルに保存します。あわせて BLOAD の待機も検出し、読み込むものを自動で尋ねます。既定で有効です。11pin や音を直接叩く機械語プログラムで誤検出するときは外してください。ファイル名は BSAVE に名前を付けなければ bsave.bin、BSAVE "MYPROG" のように名前を付ければ MYPROG.bin になります。実機と同じ速さで転送するため完了までに 20 秒以上かかりますが、進行状況が下に表示されます。|
| ファイルから LOAD ボタン| BSAVE で保存したファイルを読み込みます。読み込んだあとに BASIC で BLOAD を実行すると、その内容がポケコン側へ書き戻されます。ふつうは `BLOAD` を実行すれば自動でファイル選択が開くので、このボタンは使わなくて済みます。プログラムの途中から `BLOAD` された場合はブラウザが自動のファイル選択を許さないので、そのときにこのボタンを使ってください。実機とやり取りしているときは表示が [実機から LOAD] に変わります。|
| SIO CAPTURE チェックボックス| ここにチェックがあるとき、TEXT モードの Sio の Save で 11pin インターフェースへ出力されるテキストを復号し、text.txt というファイルに保存します。チェックを入れていないとポケコン側が送信を始めないので、Save の前にチェックしてください。|
| LOAD TXT ボタン| テキストファイルを読み込みます。読み込んだあとに TEXT モードの Sio で Load を実行すると、その内容がポケコン側のテキストエディタへ書き戻されます。ファイルは 60 FROM FILE のように行番号から始まる行を並べてください。|

BSAVE / BLOAD の仕組みと保存されるファイルの形式は [docs/emulator/](docs/emulator/) にあります。

## 実機 (11pin) とのやり取り

Arduino を間に挟むと、`BSAVE` の出力先と `BLOAD` の入力元を**ファイルではなく実機の
ポケコン**にできます。エミュレータで組んだプログラムを実機へ送り込んだり、実機の
プログラムをエミュレータへ持ってきたりできます。

使うには次の 2 つが要ります。

- **Arduino と 11 ピンの配線。** ファームウェアと配線は [arduino-11pin/](arduino-11pin/) にあります。
- **Web Serial が使えるブラウザ。** 使えない環境では画面の実機の欄がまるごと隠れ、
  従来どおりファイルでのやり取りだけになります。

### 使い方

1. 画面右の緑の欄で **[接続]** を押し、ダイアログで Arduino のポートを選ぶ
   （許可は保存されないので、開くたびに選び直します）
2. **[実機とやり取り]** にチェックを入れる。以後、`BSAVE` と `BLOAD` の相手が実機になります

**保存する（エミュレータ → 実機）**

1. エミュレータで `BSAVE` を実行する（ファイルは落ちず、データが預かられます）
2. **実機側で `BLOAD` を実行して待たせる**
3. **[送出]** を押す。17 秒ほどで送り終わり、実機の画面右下に `*` が出れば成功です

**読み込む（実機 → エミュレータ）**

1. エミュレータで `BLOAD` を実行する（[実機から LOAD] ボタンでも始められます）
2. 「実機で BSAVE を実行してください」と出たら、**実機側で `BSAVE` を実行する**
3. 40 秒ほどで取り込みが終わり、待っていたエミュレータの `BLOAD` がそのまま完了します

**保存と読み込みで実機側の操作が入れ替わります。** エミュレータが `BSAVE` する
ときは実機が `BLOAD`、エミュレータが `BLOAD` するときは実機が `BSAVE` です。
取り違えやすいので、画面にも `BSAVE → 実機 / BLOAD ← 実機` と出してあります。

### 制限と注意

- **送出は 12288 バイトまで。** Arduino 側のバッファの大きさによる制限です。
  超えるものはファイルへ保存されます。取り込み側に上限はありません。
- **待たせる側は実機にします。** 実機の `BLOAD` は `BREAK` するまで待ち続けるので、
  先に待たせておけば取りこぼしがありません。
- 転送を途中でやめたいときは **[中断]** を押します。

プロトコルと実測値は [docs/plans/2026-08-30-webserial-real-machine-io.md](docs/plans/2026-08-30-webserial-real-machine-io.md) にあります。
