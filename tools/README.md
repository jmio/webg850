# tools

解析用の作業ページ・スクリプトの置き場所です。

| 場所 | 追跡 | 用途 |
|:--|:--|:--|
| `tools/` 直下 | する | 今後の解析でも継続して使うもの（トレース用ページ、共通のフック集など）|
| `tools/tmp/` | **しない** | 1 回の解析にしか使わない使い捨てのもの |

`tools/tmp/` は `.gitignore` で除外しています。ここに置いたものは**解析が完了したら処分してください。**
残しておく価値が出てきたら、整理したうえで `tools/` 直下へ移します。

## 作業ページを作るときの注意

### 相対パスは HTML の位置ではなくリポジトリ直下を基準にする必要がある

[g800main.js](../g800main.js) は起動時に `rom.zip` と `ram.txt` を**ドキュメントの URL 基準**で読みます。

```js
hexrom.readzip("rom.zip", romfiles);
hex.read("ram.txt");
```

そのため `tools/` 以下に HTML を置くと `tools/rom.zip` を探しに行って失敗します。
HTML の `<head>` に `<base>` を入れて解決してください。

```html
<base href="../">
```

これで `rom.zip` / `ram.txt` / `<script src="./g800main.js?...">` がすべてリポジトリ直下基準になります。
`tools/tmp/` に置く場合は `<base href="../../">` です。

### 本体のコードを書き換えずに済ませる

エミュレータの関数はすべてグローバルなので、実行時にラップすればフックを差し込めます。
解析中は原則この方法を使い、[g800main.js](../g800main.js) 自体の変更は仕様が固まってから行います。

```js
var _out18 = out18;
out18 = function(x) { /* 記録する */ _out18(x); };
```

### 最終的な動作環境

本体の変更は Firefox + `file://` で動くことを保証する必要があります（[../README.md](../README.md)）。
`tools/` 以下の作業ページは解析用なのでその限りではありませんが、
そこで検証した実装を本体へ入れるときは Firefox + `file://` での確認を通してください。
