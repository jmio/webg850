# PC-G850 の I/O ポートとエミュレータの実装状況

解析中に「このポートは何か」「エミュレータは対応しているのか」を毎回調べ直さずに済むよう、
外部資料の内容とエミュレータ側の実装をまとめたもの。

## 出典

- **ポケコン PC-G850 の解析とソフト集 [I/O編]**
  http://park19.wakwak.com/~gadget_factory/factory/pokecom/io.html
  教師用マニュアルや書籍に基づく I/O ポートの解説。LCD 関係は扱っていない。
- **PC-G850V UART I/O ポート**
  https://ver0.sakura.ne.jp/doc/pcg850vuart.html
  PC-G850V の UART。独自解析のため正確でない可能性があると断り書きがある。

11pin インターフェースと UART の詳細は [11pin-uart.md](11pin-uart.md) を参照。

## エミュレータの原則

- **未実装のポートは読み出しが一律 `0x78`、書き込みは黙って捨てられる。**
  `z80inport()` の末尾の `return 0x78` がそれ。ディスパッチ表に無いポートはすべてこうなる。
- ディスパッチ表にはあるが中身が `/* 未対応 */` の関数も多い。この場合は **0 を返す**。
  「0x78 が返る」のか「0 が返る」のかで ROM の分岐が変わりうるので区別すること。
- 機種依存のポートは `in<port>_g850()` / `out<port>_g850()` のように機種名が付く。

## 10H-1FH（本体の基本機能）

| Addr | 機能 | 内容 | エミュレータ |
|:--|:--|:--|:--|
| `10H` | キーコモン入力 | キーマトリクスからデータを入力する | **実装** `in10()` |
| `11H` | キーストローブ出力（下位）| キー入力のためのストローブ信号 | **実装** `out11()`。bit4 で IA 割り込みを立てる |
| `12H` | キーストローブ出力（上位）| 同上 | **実装** `out12()` |
| `13H` | シフトキー入力 / ROM CE 切り替え | シフトキー押下中に SFT フラグ。CE1/CE0 で搭載 ROM の容量と個数が読める（`00`=16Mb×1、`01`=4Mb×2、`10`=8Mb×2、`11`=16Mb×2）| **部分実装** `in13()`。シフトキーのみ。ROM CE は返さない |
| `14H` | タイマー入力 | M 信号の 1/32 または 1/64 ごとに 1S ビットがセットされる。周期の選択は `68H` の bit7。`OUT (14H),01H` でクリア | **実装** `in14()` / `out14()` |
| `15H` | Xin 入力イネーブル | 0=入力禁止、1=入力可能。**`1FH` の Xin はこれが有効なときだけ入力できる** | **未対応**（0 を返し書き込みは無視）|
| `16H` | 割り込みフラグ | 発生原因。各ビットに 1 を書くとリセット。IA=キー入力、Kon=BREAK キー、1S=1S タイマー、/INT1=外部、SIO=シリアル | **実装** `in16()` / `out16()`。IA/Kon/1S/INT1 のみ |
| `17H` | 割り込みマスク | I/O レベルでの割り込み禁止。Z80 の DI とは無関係。0=禁止、1=許可。**SIO の割り込みマスクは `6CH` で行う** | **実装** `in17()` / `out17()` |
| `18H` | 11Pin I/F の出力レベル | 0=L 出力、1=H 出力。**bit6 (Beep) は基板上の BEEP 端子**。発振回路は無いので ON/OFF のループで音を作る | **部分実装** `out18()`。ブザーと BSAVE のキャプチャに使う。`in18()` は常に 0 |
| `19H` | ROM バンク選択 | `C000H`-`FFFFH` にマップされるシステム ROM のバンク。ROM は専用のバンクバス (BNK0-BNK6) でアドレッシングされる | **実装** `in19()` / `out19()` |
| `1AH` | BOOT ROM OFF | 0=BOOT ROM ON、1=OFF | **未対応** |
| `1BH` | RAM CE 信号選択 | `0000H`-`7FFFH` の RAM アクセス時の CE 出力先。0=/CERAM1（内蔵 RAM）、1=CERAM2（システムバス）| **形だけ実装** `ramBank` に保持するだけで動作は変わらない |
| `1CH` | IORESET 信号出力 | 拡張周辺用のリセット信号。bit0 は 1 を書いておく必要がある | **未対応** |
| `1DH` | バッテリー状態 | | **固定値** `in1d()` は常に `0x08` |
| `1EH` | ? | | **未対応** |
| `1FH` | 11Pin I/F の入力レベル / BREAK キー | BREAK キー押下中に Kon フラグ。**Xin は `15H` が入力可能のときだけ入力できる** | **実装** `in1f()`。bit7=BREAK、bit2=BLOAD 用の入力（本プロジェクトで追加）|

**バンク切り替えの注意**（資料より）: ROM や RAM のバンクを切り替えるときは、Z80 の DI や IM
命令を実行するか、割り込みベクタを変更するか、周辺機器割り込み (17H) を禁止しておかないと、
システム ROM の割り込みベクタへジャンプして暴走する。

## 60H-6FH（11pin インターフェースと UART / PC-G850）

| Addr | 機能 | 内容 | エミュレータ |
|:--|:--|:--|:--|
| `60H` | 11Pin I/F の動作 | D1D0 = `00`:従来の 3-In 3-Out I/F、`01`:8bit PIO、`10`:全二重通信の出来る UART、`11`:N/A | **未対応**（0 を返す）|
| `61H` | PIO の入出力方向 | 0=出力、1=入力 | **未対応** |
| `62H` | PIO データレジスタ | 11pin が PIO モードのときの入出力信号 | **未対応** |
| `63H` | UART のフロー制御レジスタ | フロー制御はソフトウェアで行う。入力はプルダウンされており未接続時は 0 | **未対応** |
| `64H` | CD 信号による ON の制御 | 資料でも用途不明 | **未対応** |
| `65H` | ? | | **未対応** |
| `66H` | ウエイト制御 | 0=2 ウエイトあり、1=ウエイトなし | **未対応** |
| `67H` | **CPU クロック** | **0 = 8MHz、1 = 4MHz**。UART 以外のクロック。1S タイマの周期は変わらない | **未対応** |
| `68H` | 1S タイマーの周期 / LCD ドライバのウエイト | bit7: 0=1/32、1=1/64。D1D0 で LCD のウエイト（`00`:無し、`01`:1、`10`:2、`11`:無し）| **未対応** |
| `69H` | ROM バンク選択 | `19H` と同様に `C000H`-`FFFFH` のバンクを選ぶ | **実装** `in69_g850()` / `out69_g850()` |
| `6AH` | ? | | 何もしない（0 を返す）|
| `6BH` | ? | | **未対応** |
| `6CH` | UART モードレジスタ（PC-G850）| SIO の割り込みマスクもここ | **未対応** |
| `6DH` | UART コマンドレジスタ（PC-G850）| | **未対応** |
| `6EH` | UART ステータスレジスタ（PC-G850）| | **未対応**。`//return 0x08; // 08 = UART TX RDY` というコメントアウトが残っている |
| `6FH` | UART 送受信レジスタ（PC-G850）| | **未対応** |

## 70H-74H（UART / PC-G850V のみ）

PC-G850V では UART のレジスタが `6CH`-`6FH` から移動している。

| Addr | 機能 | エミュレータ |
|:--|:--|:--|
| `70H` | UART モードレジスタ（ボーレート・割り込み）| **ディスパッチに無い** → 読み出しは `0x78` |
| `71H` | UART モードレジスタ／コマンドレジスタ（出力）、ステータスレジスタ（入力）| 同上 |
| `72H` | UART 送受信レジスタ | 同上 |
| `73H` | UART ハードウェアリセット | 同上 |
| `74H` | UART クロックイネーブル | 同上 |

ビット定義は [11pin-uart.md](11pin-uart.md) を参照。

## CPU クロックについて

資料に **`67H` の bit0 が 0 で 8MHz、1 で 4MHz** とある。実機の既定は 8MHz と考えられる。

一方、本エミュレータは G850 の既定クロックを **9000 kHz** としており（`init()`）、
`67H` は未対応なので切り替えにも追従しない。

実際に `BSAVE` の出力パルス幅を測ると、実機の実測値（外部資料）の **8/9** になっており、
この差と整合する。詳細は [bsave-signal-format.md](bsave-signal-format.md) を参照。

## アイドル時（BASIC のコマンド待ち）の I/O 基準値

異常を見分けるための目安。500ms あたりの回数。

| ポート | 方向 | 回数 |
|:--|:--|:--|
| `0x10` | in | 約 1210 |
| `0x11` | out | 約 1574 |
| `0x12` | out | 約 605 |
| `0x13` `0x14` `0x16` `0x1f` `0x40` | in | 各 約 121（1 フレームに 1 回）|
| `0x1d` `0x1e` | in/out | 各 約 243 |
